# The tools and menu actions of Hammer and TrenchBroom, by name only, grouped by
# area, each mapped to what HammerForge has for it (#1707). Names come from their
# public manuals; nothing past the name is copied. `tools/gen_parity.py` writes
# docs/parity.md from this file and the command registry, and CI holds the page
# to it.
#
# A line is `Name | mapping`, the mapping one of:
#   command ids, comma separated   covered by those commands
#   note: text                     covered some other way, as the text says
#   none                           not covered yet
#   not planned: reason            left out on purpose
# A `## Area` line starts an area.
